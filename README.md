# Project 2 – The Blueprint (Wireframing)

## Overview

This project was completed as part of a UI/UX Design Internship program.

The objective was to design a low-fidelity wireframe for an E-commerce Homepage by focusing on user flow, information hierarchy, and usability rather than visual design.

The scenario addressed a common business problem where customers abandon the shopping journey due to a cluttered layout and confusing navigation.

---

## Problem Statement

An E-commerce brand is experiencing customer drop-offs during the checkout process. Users find the website difficult to navigate, resulting in poor user experience and lower conversions.

The goal is to create a clear and logical homepage structure that guides users efficiently through the shopping journey.

---

## Objectives

* Improve information hierarchy
* Simplify navigation
* Create a clear user flow
* Highlight important Call-to-Action (CTA) buttons
* Reduce cognitive load
* Improve usability before visual design begins

---

## Design Process

### 1. Problem Analysis

Identified the key reasons behind user confusion and checkout abandonment.

### 2. User Flow Creation

Mapped the complete user journey:

Homepage → Product Category → Product Details → Add to Cart → Checkout → Payment → Order Confirmation

### 3. Low-Fidelity Wireframing

Created grayscale wireframes focusing on structure and functionality.

### 4. Design Evaluation

Reviewed layout hierarchy, CTA placement, and navigation clarity.
